ConnectWave – Deaf & Blind Communication Bridge
1. Project Name and Brief Description

Project Name: ConnectWave

Brief Description:
ConnectWave is an integrated accessibility platform designed to support both blind and deaf users. It combines navigation assistance, communication support, guardian connectivity, and emergency assistance into a single platform.

2. Problem Statement

People with visual and hearing disabilities face several challenges in their daily lives. Blind users may experience difficulties with navigation and identifying obstacles, while deaf users may face communication barriers. Emergency situations can also be difficult to handle independently. Existing solutions are often separate and fragmented.

ConnectWave aims to provide a unified platform that improves accessibility, communication, independence, and safety.

4. Tech Stack
Frontend: React.js, JavaScript, JSX, HTML, CSS
Backend: Node.js, JavaScript
API Communication: REST APIs
Package Management: npm
Accessibility Technologies: GPS/Maps, Speech-to-Text, Text-to-Speech, Camera-based assistance, Sign Language support
Configuration: Environment Variables (.env)
5. How to Run/Use the Project
Run the Project
Clone the GitHub repository.
Open the project folder.
Install the backend dependencies:
cd backend
npm install
Configure the required environment variables in the .env file.
Start the backend:
node server.js
Open a new terminal and start the frontend:
cd frontend
npm install
npm run dev
How to Use
Open the ConnectWave application.
Select the required accessibility mode.
Blind User: Use GPS navigation, voice instructions, obstacle detection, and SOS assistance.
Deaf User: Use Speech-to-Text and Sign Language communication features.
In an emergency, trigger the SOS feature to initiate the guardian alert workflow.
